## 1. Firebase 설정 (google-services.json 받기)

Firebase는 앱의 로그인(인증) 기능을 위해 필요합니다. 파일 하나를 다운받아서 폴더에 넣는 작업이에요.

1. **Firebase 콘솔 접속:** [Firebase 웹사이트](https://console.firebase.google.com/)에 구글 계정으로 로그인하고 접속합니다.
2. **프로젝트 생성:** 가운데 있는 **프로젝트 만들기**를 누르고, 프로젝트 이름에 `nangjanggo`를 입력한 뒤 계속 버튼을 눌러 생성합니다. (구글 애널리틱스는 지금 당장 필요 없으니 꺼두셔도 됩니다.)
3. **안드로이드 앱 추가:** 프로젝트 화면이 뜨면 중앙에 있는 **안드로이드 로고(로봇 모양)**를 클릭합니다.
4. **패키지 이름 입력 (중요):** Android 패키지 이름 칸에 무조건 `com.nangjanggo.app` 이라고 적어야 합니다. (아까 `app.json` 파일에 이렇게 세팅해 두었기 때문입니다.) 앱 닉네임은 비워둬도 됩니다.
5. **앱 등록 및 파일 다운로드:** **앱 등록** 버튼을 누르면, **google-services.json 다운로드** 버튼이 나옵니다. 이걸 클릭해서 다운받습니다.
6. **파일 이동:** 다운로드한 `google-services.json` 파일을 VSC를 열어서 `frontend` 폴더 바로 밑으로 끌어다 놓습니다.

## 2. GitHub Secrets 등록 (로봇에게 비밀번호 주기)

깃허브 로봇이 자동 배포를 할 때 쓸 창고 열쇠(비밀번호)들을 깃허브 금고에 넣어두는 과정입니다.

1. **Docker Hub 가입:** [Docker Hub](https://hub.docker.com/)에 들어가서 회원가입을 합니다. (아이디와 비밀번호 기억해 두세요!)
2. **Expo 가입 및 토큰 발급:** [Expo 웹사이트](https://expo.dev/)에 가입하고 로그인합니다. 오른쪽 위 프로필 누르고 **Settings** -> 왼쪽 메뉴 **Access Tokens** -> **Create token**을 눌러서 길쭉한 토큰 값을 복사해 둡니다.
3. **깃허브 저장소 세팅 접속:** 프로젝트 코드가 올라간 GitHub 레포지토리 페이지에 들어갑니다. 상단의 **Settings** 탭을 누릅니다.
4. **시크릿 메뉴 열기:** 왼쪽 메뉴에서 **Secrets and variables**를 누르고 그 아래 **Actions**를 클릭합니다.
5. **시크릿 등록:** 초록색 **New repository secret** 버튼을 눌러서 아래 3개를 하나씩 만들어 줍니다.
   * Name: `DOCKER_USERNAME` / Secret: (방금 가입한 Docker Hub 아이디)
   * Name: `DOCKER_PASSWORD` / Secret: (Docker Hub 비밀번호)
   * Name: `EXPO_TOKEN` / Secret: (아까 복사해 둔 Expo 토큰 값)

## 3. 백엔드 로컬 실행 (서버 & DB 켜기)

이제 내 컴퓨터에서 백엔드 서버와 데이터베이스를 돌려볼 차례입니다. VSC 터미널 창을 열어주세요.

1. **백엔드 폴더로 이동:** 터미널에 `cd backend`를 입력하고 엔터를 칩니다.
2. **환경변수 파일 복사:** 터미널에 `cp .env.example .env`를 입력합니다. (이렇게 하면 `.env`라는 진짜 설정 파일이 하나 생깁니다.)
3. **비밀번호 수정:** VSC 왼쪽 파일 목록에서 방금 생긴 `.env` 파일을 클릭해서 엽니다. `your_password`와 `your_root_password` 부분을 지우고 본인이 쓰고 싶은 비밀번호(예: `1234`)로 수정한 뒤 저장합니다.
4. **도커 실행:** 터미널에 `docker-compose up -d`를 입력하고 엔터를 칩니다. 뭔가가 촤르륵 다운로드되면서 실행될 겁니다.
5. **확인:** `docker-compose ps`를 쳤을 때 `app`과 `db` 두 개가 보이고 상태가 `Up` 이면 백엔드 세팅 끝입니다!

## 4. 프론트엔드 로컬 실행 (앱 화면 켜기)

마지막으로 핸드폰 화면에 띄워볼 프론트엔드 실행입니다.

1. **프론트엔드 폴더로 이동:** 터미널에 `cd ../frontend`를 입력해서 프론트엔드 폴더로 넘어갑니다.
2. **패키지 설치:** 터미널에 `npm install`을 입력합니다. (`package.json`에 적힌 필요 부품들을 알아서 다운받는 과정입니다. 시간이 조금 걸릴 수 있습니다.)
3. **앱 실행:** 설치가 끝나면 `npx expo start`를 입력합니다.
4. **화면 띄우기:** 터미널에 커다란 QR 코드가 나타납니다. 안드로이드 핸드폰에 **Expo Go** 앱을 깔고 해당 QR 코드를 스캔하면, 지금 뼈대만 만들어둔 앱 화면이 핸드폰에 켜집니다!
